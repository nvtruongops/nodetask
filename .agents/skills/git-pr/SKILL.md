# Git PR Skill

Mục đích: Tự động hóa quy trình review và tạo Pull Request sạch sẽ.

## 📋 NHIỆM VỤ

- [ ] Tự động tổng hợp file đã chỉnh sửa.
- [ ] Sinh CHANGELOG rõ ràng ngắn gọn.
- [ ] Kiểm tra toàn bộ mã nguồn không vi phạm các quy chuẩn `docs/`.
