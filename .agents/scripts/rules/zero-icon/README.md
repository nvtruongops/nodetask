# Rule: ZERO_ICON

## Goal & Scope
Enforces the strict Zero-Icon Monochrome UI design rule across all React frontend components in `apps/web/src`.
Bans imports of icon libraries (`lucide-react`, `react-icons`, `@heroicons/react`, etc.) and raw emoji symbols.

## Severity
`WARNING` (Fails in `--strict` mode)

## Dependencies
None
