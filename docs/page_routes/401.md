## 1. Overview & Route ID
- **Route ID**: `ERROR_401` (Dùng cho Analytics, Exception Auditing, Security Enforcement, RBAC)
- **Route Name**: `error.401`
- **Description**: Trang hiển thị lỗi 401 Unauthorized (`/401`). Kích hoạt khi người dùng chưa đăng nhập, token xác thực hết hạn hoặc phiên làm việc bị vô hiệu hóa khi cố gắng truy cập các tài nguyên ứng dụng yêu cầu xác thực (`/workspace`, `/settings`, `/admin`). Hướng dẫn người dùng đăng nhập lại nhanh chóng và lưu trữ đường dẫn ban đầu để tự động quay lại sau khi đăng nhập thành công.

## 10. Acceptance Criteria & QA Scenarios

```gherkin
Scenario: Guest accesses protected route /workspace
  Given an unauthenticated Guest user entering URL "/workspace"
  When the auth guard intercepts the request
  Then the system redirects to "/401"
  And displays ErrorCodeLabel "[HTTP 401: UNAUTHORIZED]"
  And clicking "[Sign In to Continue]" routes to "/auth/login?returnUrl=/workspace"

Scenario: Logged in user with expired token tries to perform RPC action
  Given a user whose session token expired 1 hour ago
  When triggering an authenticated RPC call
  Then Serverpod RPC returns 401 Status Code
  And the app redirects the user to "/401" with a session expired message
```
