## 1. Overview & Route ID
- **Route ID**: `PAGE_500` (Dùng cho Analytics, Breadcrumb, Logging, Event Tracking, RBAC)
- **Route Name**: `page.500`
- **Description**: Trang 500 Server Error (`500.md`) là màn hình bắt lỗi cấp cao (Global Error Boundary Fallback) khi Backend Serverpod gặp sự cố không thể xử lý hoặc ứng dụng Frontend gặp Uncaught React Exception. Trang giúp ngăn chặn màn hình trắng chết chóc (White Screen of Death).

## 7. Page State Machine & UI Transitions
- **State Machine Flow**:
  `IDLE` → `MOUNTED` → `RENDERED`
- **UI State Breakdown**:
  - `IDLE`: Chờ mount component.
  - `RENDERED`: Hiển thị thông báo "500 - System Error" và các nút khôi phục. Unhandled Error.
  - `RENDERED`: Hiển thị giao diện báo lỗi 500 Zero-Icon.
  - `RETRYING`: Người dùng bấm nút "Retry", reload lại trang hoặc làm mới query cache.
