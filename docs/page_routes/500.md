# 500 Server Error Boundary Route Specification (`500.md`)

> **Route Path**: `/500`  
> **Route Type**: `PUBLIC` / `SYSTEM`  
> **Layout Shell**: `PublicLayoutShell`  
> **Specification Version**: `1.4.0`  
> **Status**: `APPROVED`  

---

## Overview
Trang 500 Internal Server Error (`/500`) đóng vai trò làm React Error Boundary & Server Failure Fallback khi xảy ra lỗi không xác định tại hệ thống backend Serverpod hoặc frontend crash runtime. Trang hiển thị thông báo sự cố Zero-Icon, nút thử lại (`[RELOAD PAGE ->]`), nút chuyển về Trang chủ (`[RETURN TO HOMEPAGE]`), và nút hỗ trợ kỹ thuật (`[CONTACT SUPPORT]`).

## Non-Functional Requirements & Rendering Strategy
- **Rendering Strategy & HTTP Status Contract**:
  - **SSG / Edge SSR**: Máy chủ trả về mã HTTP Status Header `500 Internal Server Error`.
  - **Client-Side SPA / React Error Boundary**: Web Client tự động chuyển sang trang /500 view khi bắt được unhandled runtime exception.

## Interactions & Event Analytics

### Comprehensive Analytics Event Contract
- `error_500.triggered`: Fired khi có lỗi 500. Gửi kèm payload metadata:
  - `errorMessage`: `error?.message`.
  - `errorStack`: Truncated stack trace snippet.
  - `path`: `window.location.pathname`.
  - `timestamp`: `new Date().toISOString()`.
- `error_500.retry_clicked`: Fired khi nhấn `[RELOAD PAGE ->]`.
- `error_500.home_clicked`: Fired khi nhấn `[RETURN TO HOMEPAGE]`.
- `error_500.support_clicked`: Fired khi nhấn `[CONTACT SUPPORT]`.
